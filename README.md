# Telco-churn-analysis
**About the Project**
This project analyzes customer churn in a telecommunications company to understand customer retention patterns and identify customer segments with higher churn rates.

**Objectives**
- Analyze overall customer churn rates.
- Identify customer segments with the highest churn.
- Explore the relationship between contract types and customer churn.
- Provide data-driven recommendations to improve customer retention.

**Tools that I used here**
- Microsoft Excel for data standardization
- MySQL for EDA and answering business question
- Power BI for Visualization
